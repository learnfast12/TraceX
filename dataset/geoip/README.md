# GeoIP data

Raw DB-IP Lite CSVs are excluded from git (large, redistributable, and easy to re-fetch).

Place these two files here before running the backend:
- `dbip-country-lite.csv`
- `dbip-asn-lite.csv`

Source: DB-IP Lite databases (https://db-ip.com/db/lite.php), monthly free tier, CC BY 4.0.
